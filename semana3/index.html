Analogía Estructura Condicional

📚 Marco Teórico

1. ¿Qué es una estructura condicional? 🟢 VIGENTE

La estructura SI-FSI (o if en Python) permite ejecutar instrucciones solo cuando una condición es verdadera. Si la condición resulta falsa, el algoritmo continúa sin ejecutar ese bloque. Es la base de toda automatización de decisiones en negocios.

🚦
Analogía del semáforo: SI el semáforo está en rojo ENTONCES detener el vehículo FSI. Si está en verde, no hay instrucción especial: simplemente continúas.
🍞
En el expendio: SI los días para vencer son menores que 0 ENTONCES retirar el producto de la vitrina FSI. La acción ocurre solo cuando la condición se cumple; si el producto está vigente, sigue en venta.

2. La variable clave: días para vencer 🟢 VIGENTE

Toda la decisión depende de un número: días para vencer = fecha de vencimiento − fecha de hoy.

Días para vencerQué significaDecisión del expendio
Mayor que 3Producto con vida útil suficiente✅ Precio normal
Entre 0 y 3Próximo a vencer (0 = vence hoy y aún se puede vender hoy)🏷️ Rebajar o evaluar donación
Menor que 0La fecha ya pasó🚫 Retirar: no es comercializable

El umbral de 3 días es una decisión de gerencia, no una ley: en la sección de Python simularás otros valores. El 0, en cambio, sí lo fija la norma.

3. Movimiento de inventario: decisiones con lo próximo a vencer 🟢 VIGENTE

En un expendio, el inventario no solo se cuenta: se mueve. Y lo que más urge mover es lo que está más cerca de su fecha. Por eso se usa el criterio FEFO (First Expired, First Out): primero en vencer, primero en salir. Cada decisión de movimiento es, en el fondo, un SI:

SI…ENTONCES… (decisión de movimiento)Por qué
Llegan dos lotes del mismo productoExhibir primero el que vence antesFEFO: evita que el lote viejo se quede atrás y venza
dias <= 3🏷️ Rebajar el precioUn descuento acelera la venta antes de la fecha
dias <= 1 Y unidades > 10📍 Mover a la vitrina de la entrada o junto a la cajaMás visibilidad = más rotación hoy
dias <= 3 Y unidades > 20📦 Evaluar donación antes de la fechaNo alcanza a venderse todo; la Ley 1990 de 2019 promueve donar a bancos de alimentos
dias < 0🚫 Dar de baja del inventario vendibleLa fecha ya pasó: se registra como merma
📈
La pregunta gerencial: cada producto dado de baja es dinero perdido (merma). Cada rebaja es margen que se sacrifica. Decidir cuándo rebajar y cuánto es un equilibrio entre ingreso y desperdicio, y lo vas a simular en Python.

4. Condiciones compuestas: Y / O (and / or) 🟢 VIGENTE

Y / and exige que ambas sean verdaderas; O / or permite que una sola baste.

CondiciónInterpretación gerencialResultado esperado
dias >= 0 Y dias <= 3Vigente pero próximo a vencerRebajar precio
dias <= 3 Y unidades > 20Muchas unidades sin tiempo para venderlasEvaluar donación antes de la fecha
categoria = "Pan tajado" O categoria = "Ponqué"Aplica a dos líneas de productoBasta una coincidencia

5. Errores frecuentes al construir un SI 🟡 EVOLUCIONADO

ErrorQué cree el estudianteCorrección
Usar <= en vez de <"Vence hoy" ya está vencidoCon 0 días aún se vende hoy: la condición de retiro es < 0
Ignorar la rama "No"Piensa que el rombo tiene una sola salidaSiempre etiquetar Sí / No
Confundir Y con OCree que basta una condición con YY = ambas; O = al menos una
Mirar solo la fechaLas unidades no importanMover o donar depende también de cuántas unidades quedan
En Excel: olvidar separadorEscribe =SI(C2<0 "Retirar")Usar punto y coma: =SI(C2<0;"Retirar";"")

6. ¿Excel o Python? Una decisión, no una competencia 🟢 VIGENTE

La lógica del SI es la misma en ambas herramientas. Lo que cambia es para qué trabajo sirve mejor cada una. Un buen administrador no elige por costumbre: elige por el tamaño, la frecuencia y el riesgo de la tarea.

Si la tarea es…📊 Excel brilla cuando…🐍 Python brilla cuando…
TamañoSon decenas de filas que quieres ver de un vistazoSon cientos o miles de referencias, o varios archivos
FrecuenciaSe hace una vez o de vez en cuandoSe repite cada mañana: se escribe una vez y se ejecuta siempre igual
FechasHOY() y resta de celdasdate.today() y resta de fechas, igual de simple y sin copiar fórmulas
Comparar políticasUna política por hojaDecenas de escenarios en un segundo con un bucle
Errores humanosUna fórmula arrastrada mal pasa desapercibidaLa misma regla se aplica idéntica a todas las filas
CompartirTodos en la oficina lo pueden abrirGenera el reporte o la lista de retiro lista para enviar
🧭
Regla práctica: diseña y prueba la regla en Excel con pocas filas; cuando la decisión se repite todos los días o necesitas comparar escenarios, llévala a Python. No es "Excel o Python": es Excel y luego Python.
⚠️
Pista importante: si sientes que "falta algo" cuando la condición es falsa (por ejemplo, mostrar un mensaje diferente), probablemente necesitas un SI-SINO / if-else. Eso se verá la próxima semana.

📊 Excel — Función =SI() aplicada al expendio

En gestión administrativa, Excel es la primera herramienta donde aparece la lógica condicional. La función =SI() tiene exactamente la misma estructura que el pseudocódigo: condición, resultado verdadero, resultado falso.

📌
Sintaxis completa:
=SI( prueba_lógica ; valor_si_verdadero ; valor_si_falso )
En inglés: =IF( logical_test, value_if_true, value_if_false )

Condición compuesta en Excel con Y() y O()

🐍 Python — if aplicado al expendio

Excel te ayudó a diseñar la regla. Python la convierte en una rutina: el mismo código revisa todo el inventario cada mañana, resta fechas sin arrastrar fórmulas y te permite comparar políticas antes de aplicarlas. Aquí no compites contra Excel: tomas decisiones que en una hoja de cálculo serían lentas o propensas a error.

📌
Diferencias clave vs Excel:
• Python no usa FSI para cerrar — el bloque se cierra con indentación (4 espacios).
• Python usa and / or en lugar de Y() / O().
• Python usa == para comparar igualdad (no = como en Excel).
• Python resta fechas directamente: (vence - hoy).days da los días para vencer.

📝 Referencia: Pseudocódigo Cairó (SI-FSI)

📖
El pseudocódigo es una herramienta de diseño — sirve para pensar la lógica antes de escribirla en Excel o Python. No se ejecuta directamente en ningún sistema. Úsalo como borrador en papel o en el tablero.
📝 Estructura general SI-FSI (Cairó) — ver referencia 
SI condicion ENTONCES
  { instrucciones que solo ocurren si la condición es VERDADERA }
FSI

FSI = "Fin Si" — indica dónde termina el bloque condicional.
En Python no existe FSI porque el cierre se marca con indentación (4 espacios).

📝 AlertaRetiroExpendio — pseudocódigo completo 
ALGORITMO AlertaRetiroExpendio
VARIABLES
  producto          : CADENA
  dias_para_vencer  : ENTERO
INICIO
  ESCRIBIR "Nombre del producto:"
  LEER producto
  ESCRIBIR "Días para vencer:"
  LEER dias_para_vencer

  SI dias_para_vencer < 0 ENTONCES
    ESCRIBIR "🚫 RETIRAR: producto vencido"
    ESCRIBIR "Producto: " + producto
  FSI

  ESCRIBIR "Revisión completada."
FIN

Prueba de escritorio

CasoEntrada¿Condición?¿Qué imprime?
Caso 1dias_para_vencer = -2VerdaderaAlerta de retiro + producto + "Revisión completada"
Caso 2dias_para_vencer = 0FalsaSolo "Revisión completada" (vence hoy: aún se vende hoy)
📝 PlanEspecial — condición compuesta Y

  unidades         : ENTERO
INICIO

  LEER unidades

  SI dias_para_vencer >= 0 Y dias_para_vencer <= 3 Y unidades > 20 ENTONCES

5 preguntas · Haz clic en la opción correcta · 5 XP por acierto

1. ¿Cuál fórmula marca para retiro un producto cuyos días para vencer están en C2?

a) =SI(C2<=0;"RETIRAR";"Vendible")
b) =SI(C2<0;"RETIRAR";"Vendible")
c) =SI(C2<0;"RETIRAR")"Vendible"
d) =SI(C2<3;"RETIRAR";"Vendible")

✅ Correcto. Con 0 días el producto vence hoy y aún se vende hoy; con -1 ya pasó su fecha. La opción (d) retiraría productos que todavía se pueden vender con descuento.

2. En Python, ¿cómo se cierra un bloque if?

a) Con la palabra FSI
b) Con END IF
c) Con indentación — el bloque termina cuando desaparece la sangría de 4 espacios
d) Con una llave de cierre }

✅ Correcto. Python usa la indentación para delimitar bloques, no palabras clave de cierre.

3. La condición =Y(C2<=3; D2>20) es VERDADERA cuando:

a) Faltan 3 días o menos y además hay más de 20 unidades
b) Faltan 3 días o menos o hay más de 20 unidades (basta una)
c) Solo cuando faltan 3 días o menos
d) Nunca — la función Y no existe en Excel

✅ Correcto. =Y() exige que TODAS las condiciones sean verdaderas. Si una falla, el resultado es FALSO.

4. El expendio debe, cada mañana antes de abrir, revisar 1.800 referencias y comparar varias políticas de descuento. ¿Qué decisión de herramienta es más sensata?

a) Excel, porque Python solo sirve para programadores
b) Diseñar la regla en Excel con pocas filas y automatizar la revisión diaria y los escenarios en Python
c) Revisar a mano, porque las fórmulas pueden fallar
d) Python, porque su lógica condicional es distinta a la de Excel

✅ Correcto. La lógica es la misma; lo que cambia es la escala y la frecuencia. Una tarea diaria, grande y con escenarios es terreno de Python.

5. Llegan dos lotes de pan tajado: el lote A vence el 08/11 y el lote B el 12/11. Según el criterio FEFO, ¿qué se hace?

a) Exhibir primero el lote B porque está más fresco
b) Exhibir primero el lote A porque vence antes
c) Exhibir primero el lote que llegó de último
d) Mezclar ambos lotes en la misma vitrina

✅ Correcto. FEFO = primero en vencer, primero en salir. Si se exhibe primero el lote fresco, el lote A se queda atrás y termina como merma.
